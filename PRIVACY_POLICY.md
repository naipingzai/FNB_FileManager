# Privacy Policy

**Last Updated: 2026-09-16**

## Overview

FN File Manager is a local file management application. This privacy policy explains how we handle data when you use our application.

## Data Collection

**We do NOT collect any personal data.** This application operates entirely on your local device.

### What we DO NOT collect:
- Personal identification information
- Location data
- Usage analytics
- File content or metadata sent to external servers
- Device identifiers
- Network activity

### What we ACCESS locally (but do NOT transmit):
- File system directories and filenames for browsing
- File metadata (size, modification date) for display

## Data Storage

- All data stays on your device
- Application settings are stored locally using SharedPreferences
- No cloud synchronization
- No remote server communication

## Third-Party Services

This application does NOT use any third-party analytics, advertising, or tracking services.

## Permissions

This application may request the following permissions:
- Storage access: Required for file browsing and management
- No internet permission is required

## Children's Privacy

This application does not knowingly collect information from children under 13.

## Changes to This Policy

We may update this privacy policy from time to time. Changes will be posted in this file.

## Contact

If you have questions about this privacy policy, please open an issue on our GitHub repository.
